دليل إعداد جهاز الكاشير

إعداد الطابعة والثقة المحلية

خطوات بسيطة لإعداد QZ Tray على جهاز Windows، ثم اكتشاف الطابعات من لوحة الكاشير.

مهم: زر التنزيل يحمّل الحزمة فقط. المتصفح لا يستطيع فك الملفات إلى مجلدات Windows المحمية، أو تثبيت شهادة النظام، أو تشغيل PowerShell تلقائيًا. ستحتاج إلى فك الضغط وتشغيل المثبّت بنفسك مرة واحدة بصلاحية مسؤول.

⬇ تنزيل حزمة إعداد الطابعة (ZIP)

قبل البدء

  • ثبّت QZ Tray من الموقع الرسمي وشغّله.
  • ثبّت تعريف الطابعة وأضفها إلى Windows أولًا.
  • استخدم حساب Windows بصلاحية مسؤول عند تشغيل المثبّت.

التثبيت على Windows

  1. نزّل الحزمة من الزر أعلاه، ثم فك ضغطها. اترك ملفاتها معًا داخل مجلد واحد مثل C:\SERVIO-Printer-Setup.
  2. من قائمة Start، ابحث عن PowerShell، واضغط بزر الفأرة الأيمن واختر Run as administrator.
  3. انتقل إلى مجلد الحزمة وشغّل المثبّت. غيّر مقاس الورق إلى 58mm أو 80mm أو A4 حسب طابعتك:
cd C:\SERVIO-Printer-Setup
.\install-servio-qz-certificate.ps1 -PaperWidth 80mm

إذا منع Windows تشغيل السكربت، لا تغيّر سياسة التنفيذ ولا تتجاوز حماية النظام. تحقق من مصدر الحزمة واطلب من مسؤول النظام مراجعتها أو تواصل مع قناة دعم SERVIO المعتادة.

  1. أدخل اسم الطابعة كما يظهر في Windows، أو اتركه فارغًا لاكتشافها لاحقًا من SERVIO.
  2. بعد ظهور نجاح التثبيت، أغلق QZ Tray بالكامل من أيقونة شريط النظام ثم شغّله مجددًا.
  3. افتح SERVIO، ثم لوحة الكاشير ← واجهة الكاشير ← إعداد الطابعة. اضغط الاتصال واكتشاف الطابعات، وحدد الطابعة، ثم احفظ واختبر.

إذا ظهرت نافذة الثقة

في تفاصيل الشهادة، يجب أن تطابق بصمة SHA-1 شهادة SERVIO التالية:

9D:F0:6C:BD:33:BC:1F:0F:D3:86:01:25:D8:97:B1:A9:91:CD:4B:1F
  • إذا ظهر Validity: Invalid Certificate أو Trusted: Untrusted website، أعد تشغيل المثبّت بصلاحية مسؤول، ثم أغلق QZ Tray بالكامل وأعد تشغيله. تحقق أيضًا من صحة تاريخ ووقت Windows.
  • ظهور Signature: Not Required لطلب QZ باسم connect طبيعي؛ لكن Invalid Certificate ليس طبيعيًا ويجب أن يزول بعد تحميل شهادة الثقة.
  • إذا ظهرت مطالبة الإذن بعد نجاح التثبيت، اختر Remember this decision ثم Allow مرة واحدة. لا تختَر Block.

ملف الشهادة داخل الحزمة عام. لا تتضمن الحزمة مفتاح التوقيع الخاص، ولا تطلبه من أي شخص.

الإشعارات في الخلفية على الأجهزة المختلفة

  1. من لوحة الكاشير افتح تبويب الإشعارات والدليل واضغط تفعيل الإشعارات على هذا الجهاز. لن يطلب SERVIO الإذن تلقائيًا عند فتح الصفحة.
  2. اسمح بإشعارات المتصفح في Windows أو macOS أو Android، واترك الجهاز متصلًا بالإنترنت. وضع عدم الإزعاج أو إعدادات توفير الطاقة قد تؤخر الإشعار أو تمنعه.
  3. على iPhone أو iPad يلزم iOS/iPadOS 16.4 أو أحدث: من قائمة المشاركة في Safari اختر Add to Home Screen / إضافة إلى الشاشة الرئيسية، ثم افتح نسخة SERVIO المثبتة وفعّل الإشعارات من التبويب أعلاه. تبويب Safari العادي لا يستقبل الإشعارات بعد إغلاقه.

تصل إشعارات الطلبات الجديدة واستدعاءات الخدمة للكاشير المشترك في الفرع نفسه فقط. تعرض شاشة القفل نوع الحدث ورقم الطاولة دون اسم العميل أو رقم هاتفه أو تفاصيل الطلب. الضغط على الإشعار يفتح لوحة الكاشير، وما زال تسجيل الدخول مطلوبًا. لا يمكن ضمان التسليم في كل الظروف.

TA‑80U حراري 80 مم هو مرجع برمجي لمسار صورة ESC/POS مع أمر قصّ؛ لم يُتحقق منه على جهاز فعلي. طباعة A4 تمر عبر تعريف النظام. «قُبلت المهمة» لا تعني تأكيد خروج الورقة.

  • macOS: ثبّت QZ Tray من موقعه الرسمي، وأضف الطابعة إلى macOS أولًا عبر تعريف الشركة المصنّعة أو إعدادات الطابعات، ثم افتح إعدادات الطابعة في SERVIO واكتشف الطابعة واحفظها واختبرها. يعمل المسار الصامت عبر جسر QZ عند دعم الطابعة والتعريف، لكن لم تُجرَ اختبارات ميدانية لطرازات macOS.
  • Android: يمكن فتح نافذة الطباعة اليدوية من إجراء الطباعة اليدوي داخل الفاتورة، إذا كان الجهاز والطابعة يوفّران خدمة طباعة متوافقة. بعض الطابعات تحتاج تطبيق خدمة طباعة من الشركة المصنّعة أو تطبيقًا مساعدًا. لا تطبع نسخة الويب بصمت مباشرة عبر USB أو Bluetooth.
  • iPhone/iPad: استخدم إجراء الطباعة اليدوي في الفاتورة واختر طابعة تدعم AirPrint من نافذة النظام. لا توفر نسخة الويب طباعة صامتة مباشرة عبر USB أو Bluetooth.
  • USB / Bluetooth / Wi-Fi: على Windows وmacOS يجب أن تكون الطابعة مثبتة ومعروفة لنظام التشغيل أو لـ QZ Tray. دعم الاتصال والطراز يعتمد على تعريف الطابعة؛ لم يتم التحقق الميداني إلا من منطق طباعة ESC/POS المرجعي لطراز TA-80U على مستوى الكود، وليس بطابعة فعلية.

للدعم، شارك نوع الجهاز وإصدار النظام والمتصفح ووقت المشكلة دون بيانات العملاء. لا ترسل رمز PIN أو عنوان اشتراك الإشعار أو مفاتيح سرية، واستخدم قناة دعم SERVIO المعتادة لدى نشاطك.

دقة حالة الطباعة: «قُبلت المهمة من جسر الطباعة/نظام التشغيل» لا تعني تأكيد خروج الورقة. عند فشل الطباعة الصامتة لن تفتح نافذة النظام تلقائيًا؛ استخدم خيار الطباعة اليدوية المنفصل عند الحاجة.

CASHIER DEVICE SETUP

Printer and local trust setup

Set up QZ Tray on Windows, then discover and select printers from the cashier dashboard.

Important: The download button only downloads the package. Browsers cannot extract files into protected Windows folders, install system certificates, or run PowerShell automatically. Extract the ZIP and run the installer yourself once as an administrator.

⬇ Download printer setup package (ZIP)

Before you start

  • Install and run QZ Tray from its official website.
  • Install the printer driver and add the printer in Windows first.
  • Use a Windows account with administrator rights to run the installer.

Install on Windows

  1. Download the package above and extract it. Keep all files together in one folder, such as C:\SERVIO-Printer-Setup.
  2. Open Start, search for PowerShell, right-click it, and select Run as administrator.
  3. Change to the package folder and run the installer. Change the paper size to 58mm, 80mm, or A4 as appropriate:
cd C:\SERVIO-Printer-Setup
.\install-servio-qz-certificate.ps1 -PaperWidth 80mm

If Windows blocks the script, do not change execution policy or bypass system protections. Verify the package source and ask your system administrator to review it or use your usual SERVIO support channel.

  1. Enter the printer name exactly as it appears in Windows, or leave it blank and discover printers from SERVIO later.
  2. When installation succeeds, fully exit QZ Tray from the system tray and start it again.
  3. Open SERVIO, go to Cashier Dashboard → Cashier interface → Printer setup, select Connect and discover printers, choose your printer, then save and test.

If the trust window appears

The certificate SHA-1 fingerprint in QZ Tray should match:

9D:F0:6C:BD:33:BC:1F:0F:D3:86:01:25:D8:97:B1:A9:91:CD:4B:1F
  • If QZ shows Validity: Invalid Certificate or Trusted: Untrusted website, rerun the installer as administrator, fully exit QZ Tray, and restart it. Also check the Windows date and time.
  • Signature: Not Required for a QZ connect request is normal; Invalid Certificate is not and should clear after the trust certificate loads.
  • If an authorization prompt remains after successful setup, select Remember this decision and then Allow once. Do not select Block.

The certificate in the package is public. The package does not include the private signing key; never share or request that key.

Background notifications on different devices

  1. In the cashier dashboard, open Notifications & guide and press Enable notifications on this device. SERVIO does not prompt automatically on page load.
  2. Allow browser notifications on Windows, macOS, or Android and keep the device online. Do Not Disturb or power-saving settings may delay or prevent delivery.
  3. On iPhone/iPad, iOS/iPadOS 16.4 or later is required: in Safari's Share menu choose Add to Home Screen, open the installed SERVIO web app, and enable notifications from the tab above. A regular Safari tab does not receive notifications after it is closed.

New-order and service-call alerts go only to opted-in cashiers for the same branch. Lock-screen messages show the event type and table number only, never customer names, phone numbers, or order details. Tapping an alert opens the cashier dashboard, where sign-in is still required. Delivery cannot be guaranteed in every circumstance.

TA-80U 80 mm thermal is a code-level reference for ESC/POS raster output and a cut command; it has not been verified on physical hardware. A4 printing uses the OS driver. “Accepted” does not confirm paper output.

  • macOS: Install QZ Tray from its official website and add the printer in macOS using the manufacturer driver or printer settings. In SERVIO printer settings, discover, save, and test it. Silent printing uses the QZ bridge when the printer and driver support it; physical macOS printer models have not been field-tested.
  • Android: The invoice's separate manual print action can open the OS print dialog when the device and printer provide a compatible print service. Some printers require a manufacturer print service or companion app. The web app cannot silently print directly over USB or Bluetooth.
  • iPhone/iPad: Use the invoice's manual print action and select an AirPrint-capable printer from the system dialog. The web app cannot silently print directly over USB or Bluetooth.
  • USB / Bluetooth / Wi-Fi: On Windows and macOS, the printer must be installed and visible to the operating system or QZ Tray. Support depends on the driver and printer model. TA-80U is the ESC/POS reference model in code; no physical printer has been tested.

For support, share the device type, OS/browser versions, and approximate issue time without customer data. Never send a PIN, push subscription endpoint, or secret key; use your business's usual SERVIO support channel.

Print status: “Accepted by the print bridge/OS” does not confirm that paper physically came out. A failed silent print never opens the system dialog automatically; choose the separate manual-print action if needed.
